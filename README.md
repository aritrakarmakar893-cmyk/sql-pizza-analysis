# 🍕 Pizza Sales Analysis — SQL Project

## 📌 Project Overview

This project is a **SQL-based Pizza Sales Analysis** designed to explore and analyze pizza sales data using SQL queries.

The project focuses on extracting meaningful business insights from raw sales data, including **total revenue, total orders, total pizzas sold, average order value, cumulative revenue, sales trends, and pizza-wise performance**.

The main goal of this project is to demonstrate practical SQL skills such as **aggregation, joins, subqueries, window functions, grouping, sorting, filtering, and date/time analysis**.

---

## 🎯 Objectives

The key objectives of this project are:

* Analyze overall pizza sales performance.
* Calculate total revenue generated.
* Calculate total number of orders.
* Calculate total pizzas sold.
* Find the average order value.
* Identify the best-selling pizzas.
* Analyze sales by pizza category.
* Analyze sales by size.
* Identify daily and monthly sales trends.
* Calculate cumulative revenue using SQL window functions.
* Determine the percentage contribution of different pizza categories.
* Extract useful business insights from the sales data.
